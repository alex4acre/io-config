      Build configuration

      Builds the bus configuration (ENI + ini) for exactly the devices in the list above, present or not: each device from its ESI (without one: from the configuration the list started from, else from its EEPROM), with the settings the list kept for it. Nothing is written until you press "Write to the EtherCAT master". If the master can't take it, it goes to its files and takes effect at the next master start. The list stays after a write.

          Saved configurations

          Active saves the ENI/ini the master runs now (no settings). Proposed saves this list with its settings and the ENI/ini built from it. "Activate" writes a saved configuration to the master (the current one is backed up first; the bus stops briefly; the list is not changed). "Open" makes it the device list. Also by REST (POST api/v1/saved/<name>/activate) or the Data Layer (write the name to io-config/activate, state in io-config/activation/state).
